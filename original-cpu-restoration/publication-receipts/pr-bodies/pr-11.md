## Motivation

Torch search and inference need TaylorF2 templates that accept tensor parameters and frequency grids, with numerical parity and explicit precision boundaries.

## Contents

TaylorF2 variants, SPA template support, tidal helpers, batch generation and numerical parity tooling. The optional `PYCBC_TAYLORF2_TRITON=1` CUDA batch route fuses frequency evaluation while reusing existing validation, PN coefficients, reference phases, normalization, polarization rotation and per-row support. CPU, missing Triton, ROCm and reverse- or forward-mode gradient inputs use the ordinary Torch path. Selected compilation/launch failures propagate. New tests cover numerical edge cases, exact padding, gradient fallback and 65,536-row launch indexing.

Sparse float64 phase-polynomial evaluation reduces repeated work while preserving the original float32 path and reference phases.
